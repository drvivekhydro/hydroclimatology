Getting started#

Introduction to Python#

Why Python for this course?#

Most of the work in applied hydroclimatology is data work: reading a rain-gauge or streamflow record, cleaning gaps and error flags, computing climatologies and anomalies, and opening gridded climate data (reanalysis, satellite products, CMIP6 output) stored in NetCDF files. Python, with NumPy, pandas, Matplotlib, and xarray, does all of this in a few lines and is the toolchain used throughout the course — the energy balance model of Lecture 4, the finite-difference schemes of Lectures 9–11, and the CMIP6 processing of Module 4 all build on what is below.

This lecture is a fast tour of the language and these libraries. If you have never programmed, work through every cell; if you know another language, skim to the NumPy, classes, and NetCDF sections.

  • Indenting of the source code has a meaning!

    • the indentation of your code organizes it into blocks within blocks within blocks.

  • assignments of variables use =, to compare two variables we use ==

  • also: logical operators are words (and, or, not) not symbols

Classes and objects#

A class bundles data (attributes) together with the functions that act on that data (methods). You have already used classes without noticing: a NumPy array, a pandas DataFrame, and an xarray Dataset are all objects with attributes (.shape, .columns) and methods (.mean(), .plot()).

Writing your own class is useful whenever a thing has both state and behaviour. A weather station, for example, has a location and a growing record of daily values, and we want to ask it for its mean or its number of hot days.

class Station:
    \"\"\"A weather station and its record of daily mean temperature.\"\"\"

    def __init__(self, name, lat, lon):
        self.name = name          # attribute
        self.lat = lat
        self.lon = lon
        self.temperature = []     # daily values [degC], filled in later

    def add_day(self, value):     # method
        self.temperature.append(value)

    def mean(self):
        return sum(self.temperature) / len(self.temperature)

    def hot_days(self, threshold=30.0):
        return sum(1 for t in self.temperature if t > threshold)


mandi = Station("Mandi", 31.71, 76.93)
for t in [28.4, 31.1, 33.0, 29.7, 30.6]:
    mandi.add_day(t)

print(mandi.name, "mean:", round(mandi.mean(), 2), "degC")
print("hot days (>30):", mandi.hot_days())

The __init__ method runs when the object is created and sets up its attributes. self is the object itself, passed automatically, so mandi.add_day(31.1) becomes Station.add_day(mandi, 31.1).

This is exactly the pattern of the EBM class you meet in Lecture 4: its state is the temperature and the current year, and its method steps that state forward one year at a time. Recognising the pattern here makes that notebook easier to read.

import numpy as np
import matplotlib.pyplot as plt
import pandas as pd

x = np.arange(0,300) # Numbers from 0 to 30 (30 not included)
y = np.sin(np.arange(0,300)) + np.random.normal(0,5,300) # Create sinus

                         'values': y})

Gridded data: NetCDF and xarray#

Climate and reanalysis data come as multi-dimensional arrays — a variable on a latitude–longitude–time grid — stored in NetCDF files. xarray opens these and lets you select, average, and plot by named dimension instead of by array index.

We use a small built-in example dataset: 2-metre air temperature from the NCEP/NCAR reanalysis over North America (four times daily, 2013–2014). Everything below works the same way on an ERA5, IMD, or CMIP6 file.

import xarray as xr

ds = xr.tutorial.open_dataset("air_temperature")   # downloads ~4 MB on first use
ds

# 'air' is 2-m air temperature in kelvin; convert to degC and inspect one time step
air_c = ds["air"] - 273.15
air_c.isel(time=0)

# a map: the first time step
air_c.isel(time=0).plot(cmap="coolwarm")

# a regional-mean time series: average over a lon-lat box
region = air_c.sel(lat=slice(50, 30), lon=slice(240, 260))   # roughly the US Great Plains
region_mean = region.mean(dim=["lat", "lon"])

region_mean.plot()

# a smoothed version
region_mean.rolling(time=20, min_periods=1).mean().plot()
